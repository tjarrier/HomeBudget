# Agents

entier avant de toucher au code : il contient les quatre règles qui ne se négocient

Ce fichier existe pour que les agents qui cherchent `AGENTS.md` y soient renvoyés —
il n'y a pas deux jeux de consignes, seulement deux portes d'entrée.
